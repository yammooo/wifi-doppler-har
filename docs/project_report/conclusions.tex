\section{Conclusion}
\label{sec:conclusion}

This study tested whether a convolutional student could replace SHARP
preprocessing by mapping raw CSI windows directly to Doppler maps. The students
could memorize small sets, but even the corrected shared-antenna,
frequency-aware 2-D model converged to a center-ridge shortcut and reached only
\(40.89\%\) frozen-classifier accuracy. In contrast, explicit affine phase
correction followed by the fixed Doppler transform matched legacy SHARP at
\(91.52\%\). The main lesson is that phase invariance matters more here than
decoder capacity or stronger pixel losses, and that MSE is not a reliable proxy
for HAR utility. A key difficulty was target provenance: recomputed SHARP maps
themselves were poorly matched to the legacy classifier. Future work should
align teacher and classifier data, then learn from sanitized CSI or unroll the
sparse phase-correction stage. The affine method is immediately applicable as a
strong, explicit baseline, but equivalent end-to-end runtime remains to be
measured.
