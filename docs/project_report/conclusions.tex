\section{Conclusion}
\label{sec:conclusion}

Direct raw-CSI regression is feasible but is not yet a SHARP replacement.
With official teacher supervision, the corrected shared-antenna,
frequency-aware model localizes held-out motion and reaches \(63.09\%\)
frozen-classifier accuracy. However, smoothed peaks erase distinctions between
walking, jumping, and running, leaving a large gap to SHARP's \(91.36\%\).
Explicit affine phase correction followed by the fixed Doppler transform also
reaches \(91.36\%\), with substantially better map and motion-support fidelity.
The main lesson is not that neural approximation fails completely, but that
target consistency, phase invariance, and sharp spectral geometry matter more
than decoder size alone. Future work should learn after explicit sanitization
or unroll the sparse phase stage, and should measure equivalent end-to-end
runtime and repeated-seed uncertainty.
